1. Problem & Aim

Cyberbullying on digital platforms causes severe psychological distress. Traditional keyword blocklists fail against misspelled words, sarcasm, and indirect attacks.

Project Aim: Design, evaluate, and deploy a robust contextual NLP classification system that accurately distinguishes bullying-related language from benign speech, augmented with Generative AI counter-speech.

2. Dataset & Preprocessing
  • Corpus: CardiffNLP TweetEval Offensive benchmark (14,230 social media comments).
  • Splits: Stratified 75% Train (10,672), 12.5% Validation (1,779), 12.5% Test (1,779).
  • Conservative Normalization: Stripped noise URLs & handles while preserving affective punctuation and emojis.
  • N-Gram Extraction: Word unigrams, bigrams, and trigrams (1–3 ngrams, 39,256 vocabulary).
3. GenAI & Prompt Engineering

Integrated an Explainable AI & Counter-Speech Generator using few-shot in-context learning:

  • Role Prompting: NLP Safety Auditor persona.
  • Chain-of-Thought: Identifies linguistic attack vectors.
  • Restorative Rephrasing: Converts hostile rants into polite disagreement.

5. Model Implementations
Model 1: Logistic Regression
Linear classification baseline with sublinear TF-IDF scaling and balanced class weighting ($L_2$ regularized).
Model 2: Calibrated Linear SVM
Maximum-margin hyperplane with Platt Scaling sigmoid calibration for calibrated probabilities: $P(y=1|f(x)) = \frac{1}{1 + e^{Af(x)+B}}$.
Model 3: Fine-Tuned DistilBERT
6-layer bidirectional Transformer with 12 self-attention heads capturing full syntactic context across sequences.
6. Experimental Results
Model Accuracy Macro-F1 Latency
TF-IDF + LogReg 73.8% 0.697 ~2 ms
TF-IDF + SVM 75.5% 0.681 ~3 ms
DistilBERT 93.6% 0.934 ~45 ms

Key Insight: Traditional TF-IDF baselines excel at overt keywords with sub-3ms latency, while DistilBERT delivers superior contextual detection on subtle, sarcastic comments.
