🛡️ CYBERSHIELD: CONTEXTUAL NLP & MULTIMODAL CYBERBULLYING INTERCEPTION

Real-Time Social Media Moderation, Screenshot OCR, LIME Feature Attribution & SaaS Administration

Author: Kamakhya Kanzade Specialization: Final-Year Natural Language Processing (NLP) & System Architecture Tech Stack: Python, Flask, PyTorch/DistilBERT, Scikit-Learn, LIME, MongoDB, Windows OCR GitHub: github.com/Kamakhya07/NLP_project
1. Problem & Objectives

Online harassment across social networks causes severe psychological trauma. Traditional keyword blocklists fail against obfuscated text, Hinglish transliterations, sarcasm, and offensive images/screenshots.

Core Objective: Build a high-throughput, multi-stage NLP safety pipeline capable of real-time tweet interception, token-level explainability, multimodal screenshot OCR, and full administrative governance.

2. Dataset & Preprocessing
  • Benchmark Corpus: CardiffNLP TweetEval Offensive benchmark (14,230 social records).
  • Stratified Splits: 75% Train (10,672), 12.5% Val (1,779), 12.5% Test (1,779).
  • Conservative Normalization: Stripped URL noise & handle mentions while strictly preserving affective punctuation, emoticons, and casing signals.
  • N-Gram Space: Sublinear TF-IDF (1–3 word n-grams, 39,256 active vocabulary).

3. Multimodal Screenshot OCR

Integrated a local Windows Native OCR Engine allowing direct upload of social screenshots (Twitter, Instagram, WhatsApp, Reddit):

  • Direct Image Parsing: Supports PNG, JPG, WEBP formats.
  • Text Extraction: Cleans bounding boxes and normalizes extracted multiline text.
  • Automated Classification: Extracted strings are fed into the active NLP model and LIME explainer with side-by-side visual previews.

5. Model Implementations & Calibration
1. Logistic Regression:
$L_2$-regularized linear baseline with balanced class weights and fast 2ms inference.
2. Platt-Calibrated Linear SVM:
Maximum-margin hyperplane with Platt sigmoid calibration for well-calibrated posterior probabilities: $P(y=1|f(x)) = \frac{1}{1 + e^{Af(x)+B}}$.
3. Fine-Tuned DistilBERT:
6-layer bidirectional Transformer with 12 self-attention heads capturing long-range contextual semantics and subtle sarcasm.
6. Explainable AI (LIME & Tokens)

Integrated Local Interpretable Model-agnostic Explanations (LIME):

  • Token Attribution: Extracts exact positive and negative contribution weights for each word token.
  • Visual Badge Highlighting: Red badges indicate toxic triggers; green badges indicate mitigating context.
  • Evidence Accordion: Embedded inside the Admin Moderation Queue for transparent disciplinary decisions.
7. Modern SaaS Admin Command Center
  • 4 Core KPI Cards: Total Posts, Flagged Posts, Total Users, Blocked Accounts.
  • Moderation Queue: Compact cards, risk levels, and 1-click Approve / Reject / Block actions with modal confirmations.
  • User Management: Real-time filtering, search, strike counters, and admin block immunity protection.
  • Audit Trail & Logs: Immutable administrative activity log recording every decision.
